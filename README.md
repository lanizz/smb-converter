# 共享转换器（Mac 菜单栏版）

顶部菜单栏常驻小工具：Windows `\\server\share\路径` ↔ Mac `smb://server/share/路径`，
一键转换、复制，并可直接在 Finder 中挂载打开共享。

## 安装（用 DMG）

打开 `dist/共享转换器.dmg`，把 **共享转换器.app** 拖进 **Applications** 文件夹即可。
首次运行若被 Gatekeeper 拦截：右键 app →「打开」→ 确认一次
（或「系统设置 → 隐私与安全性」里点「仍要打开」）。

要求 **macOS 13 或更高**，Apple Silicon 与 Intel 通用。

## 日常用法（最快流程）

1. 在邮件/IM/文档里复制一条 Windows 或 Mac 的共享路径
2. 点一下菜单栏图标 —— 弹窗**自动读取剪贴板、转换并复制好结果**
3. 直接去目标窗口 `⌘V` 粘贴即可

输入框只接受一个路径；粘贴多行时自动取第一条。弹窗内回车也会复制反向结果。

## 功能

- **自动识别方向**：`\\server\…`、`smb://…`、`file://…`、`//server/…` 均可
- **自动编解码**：空格→`%20`、中文→UTF-8 百分号编码，反向自动解码
- **在 Finder 中打开**：调用系统挂载 SMB 共享，存过凭据的共享直接进入
- 点击 Windows / Mac 结果卡片复制对应格式
- **开机启动**：弹窗左下角勾选（系统登录项，可在「系统设置→通用→登录项」管理）
- 纯菜单栏程序，不占 Dock

## 从源码构建

```bash
./build.sh
# 产物：
#   build/共享转换器.app
#   dist/共享转换器.dmg
```

零第三方依赖，仅用系统 SwiftUI / AppKit / ServiceManagement；
图标由 `makeicon.swift` 用 Core Graphics 生成。重新构建会自动刷新图标。

## 卸载

退出菜单栏 app 后，把 app 拖到废纸篓。开过开机启动的，先在弹窗取消勾选
（或在「系统设置→通用→登录项」移除）。
