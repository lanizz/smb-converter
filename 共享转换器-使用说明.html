共享转换器

Windows 与 Mac 之间 SMB 共享路径一键互转 · 菜单栏常驻小工具

macOS 13 或更高 Apple 芯片 + Intel 通用 版本 1.0
1. 安装 2. 首次打开 3. 快速上手 4. 界面说明 5. 转换示例 6. 在 Finder 打开 7. 开机启动 8. 卸载 9. 常见问题

1安装

通过 DMG 安装，只需拖一下。

  1. 双击打开 共享转换器.dmg。
  2. 在弹出的 Finder 窗口中，把 共享转换器 图标拖到 Applications（应用程序） 文件夹上。
  3. 等待拷贝完成，点窗口左上角推出 DMG（或在访达侧边栏点推出符号 ⏏）。
  4. 打开「应用程序」文件夹（或启动台），找到 共享转换器，准备首次启动。
💡 为什么要装到「应用程序」 装在 /Applications 下，开机启动、系统登录项管理和后续更新都最稳定；不要直接在 DMG 里运行。

2首次打开（重要）

应用未经 Mac App Store 公证，首次启动可能被 Gatekeeper 拦截，按下面任一方式放行即可。

方式 A：右键打开（推荐，最快）

  1. 在「应用程序」里找到 共享转换器。
  2. 按住 Control 键点按（或右键 / 双指点按）图标，选择「打开」。
  3. 弹窗里会多出一个「打开」按钮，点它即可。此后正常双击启动不再拦截。

方式 B：系统设置中「仍要打开」

如果已经双击过、被拦下，可前往：

系统设置 → 隐私与安全性 底部提示“已阻止使用共享转换器” → 仍要打开

方式 C：提示「已损坏，应移到废纸篓」时

个别系统对未公证应用更严格。打开「终端」，粘贴下面这行并回车，输入开机密码（输入时不显示字符），再重新启动应用：

xattr -dr com.apple.quarantine /Applications/共享转换器.app
安全说明 本工具为本地开源程序，不联网、不收集数据；出现提示仅因未购买 Apple 开发者证书做公证，并非应用本身有问题。

3快速上手（3 步）

最常用的流程：复制路径 → 点图标 → 粘贴结果。

  1. 在邮件、聊天或文档里，复制一条共享路径（Windows 的 \\服务器\… 或 Mac 的 smb://… 都行）。
  2. 点一下屏幕顶部菜单栏的共享转换器图标。它会自动读取剪贴板并完成转换，结果已经复制好。
  3. 切到目标窗口，按 ⌘+V 粘贴即可。
💡 面板会保持打开 自动复制后面板不会消失，你可以核对结果、点「在 Finder 中打开」，或点别处关闭它。

4界面说明

程序没有 Dock 图标，只在顶部菜单栏显示一个网络文件夹小图标。

1
输入框（3 行）：粘贴或输入路径，自动识别方向。只接受一条路径；粘贴多条时自动取第一条。聚焦时蓝色高亮。
2
检测状态：绿点表示已识别，显示转换方向；右侧提示 ↵ 可复制反向结果。
3
在 Finder 中打开：直接挂载并打开这条共享，省去手动「连接服务器」。详见第 6 节。
4
Windows / Mac 结果卡：点任意卡片即可复制该格式。绿色为 Windows，蓝色为 Mac。
5
开机启动 / 退出：勾选开机自启；「退出」关闭菜单栏程序。

5转换示例

支持反斜杠、正斜杠、smb://、file://，并自动处理中文与空格编码。

Windows → Mac

复制到的 Windows 路径\\fileserver\团队共享\2026 计划.xlsx
→
得到 Mac 路径smb://fileserver/%E5%9B%A2%E9%98%9F…/2026%20%E8%AE%A1%E5%88%92.xlsx

Mac → Windows

复制到的 Mac 路径smb://fileserver/share/a b/测试.docx
→
得到 Windows 路径\\fileserver\share\a b\测试.docx
💡 编码规则 空格会变成 %20，中文按 UTF-8 转成 %XX；反向转换会自动解码回原始中文和空格。文件名里本身带 % 也能正确处理。

6在 Finder 中打开

不想只复制路径？点蓝色大按钮直接挂载共享。

  1. 面板里已有路径时，点「在 Finder 中打开」。
  2. 系统会连接 SMB 共享；第一次访问该服务器可能要求输入账号和密码。
  3. 建议勾选「在我的钥匙串中记住此密码」，以后即可直接打开、免再登录。
注意 挂载与认证由 macOS 系统完成（等同访达的「前往 → 连接服务器」），账号密码保存在系统钥匙串中，本工具不接触、不留存。

7开机启动

勾选面板左下角的「开机启动」即可在登录后自动常驻菜单栏。它使用 macOS 标准登录项管理，也可随时在以下位置查看或移除：

系统设置 → 通用 → 登录项与扩展 → 在后台允许

取消勾选即关闭自启，无需其它操作。

8卸载

  1. 先点菜单栏图标 →「退出」，关闭程序。
  2. 若开过开机启动，先取消勾选（或在「登录项」中移除）。
  3. 打开「应用程序」，把 共享转换器 拖到废纸篓即可。

9常见问题

菜单栏里找不到图标怎么办？

顶部菜单栏图标过多时可能被系统折叠或挤到右侧。可先确认程序在运行（活动监视器搜索「共享转换器」）。

macOS 上可按住 ⌘ 键拖动菜单栏图标重新排列。重新从「应用程序」双击启动也可让它重新出现。

点了图标，面板没有自动填内容？

只有当剪贴板内容“长得像”共享路径（以 \\、//、smb:// 或 file:// 开头）时才会自动填入，避免覆盖你正在做的事。直接在输入框里 ⌘+V 粘贴同样会立即转换并复制。

打开共享时提示要输入账号密码？

这是 macOS 访问 SMB 服务器的正常认证。输入该共享的账号密码并勾选「在钥匙串中记住」，以后免登录。具体账号请向共享服务器管理员获取。

转换出来的中文变成了一堆 %XX，正常吗？

正常。Mac 的 smb:// 链接要求对中文、空格等做百分号编码，%E5%9B%A2… 正是「团」等字的 UTF-8 编码，访达能正确识别并打开。反向转换会自动还原成中文。

支持哪些系统和芯片？

支持 macOS 13（Ventura）及以上，Apple 芯片（M 系列）与 Intel 均为原生通用二进制，无需 Rosetta。

应用会联网或收集数据吗？

不会。所有转换都在本地完成；唯一的系统调用是按你要求打开 SMB 共享，由 macOS 直接处理。
